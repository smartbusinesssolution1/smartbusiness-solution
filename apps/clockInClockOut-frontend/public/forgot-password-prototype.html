Underlying Backend Architecture

The Login screen connects to POST /api/v1/auth/login on port 3001. If the user forgets their password, they click the recovery trigger to initiate the secure token issuance workflow.

Security Defense Mechanism

Timing Attack Protection: If an unknown email is submitted, the backend performs a dummy password hash so response time is indistinguishable from valid accounts.
